# Contributing

## Development workflow

1. Create a feature branch.
2. Make focused changes with tests/docs updates.
3. Run checks from `Makefile`.
4. Open a PR with rationale and validation output.

## Coding standards

- Perl: follow `.perlcriticrc` and `.perltidyrc`.
- Nextflow: keep modules small and composable.
- Documentation: update implementation-driven docs only.
